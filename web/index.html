Roop

한 틱에 한 결정.

작은 로컬 모델은 “알아서” 하지 않습니다. Orchestrator가 상태를 보고, 역할 하나를 고르고, 하니스만 실행한 뒤 Verifier가 실측합니다.

틱 돌려보기 루프 해부

매 틱의 6단계

프로그램이 모델을 부릅니다. 모델이 프로그램을 부르지 않습니다.

  1. 01
    상태만 본다

    SQLite task · .agent/state · git

  2. 02
    역할 하나

    Planner · Coder · Reviewer · Tester

  3. 03
    역할용 패킷

    짧은 시스템 프롬프트 + Task JSON + 파일 슬라이스

  4. 04
    스키마 강제

    JSON만. 파싱 실패면 1회 재생성 후 Blocked 후보

  5. 05
    하니스만 실행

    모델 서술 ≠ 실행. 쓰기는 기본 .agent/**

  6. 06
    Verifier 실측

    exit code · allow_paths · next_state는 코드가 결정

대기

재생을 누르면 첫 틱이 시작합니다

Orchestrator는 큐에서 pending task 하나를 집어 이번 틱의 역할만 고릅니다. 계획·코딩·테스트를 한 프롬프트에 넣지 않습니다.
